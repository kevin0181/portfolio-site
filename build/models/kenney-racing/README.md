The 15 selected GLBs total 288,384 bytes. Files are copied unchanged from the official archive's GLTF format folder. Embedded resources require no external model-host requests. Attribution is optional under CC0; the help dialog credits Kenney.

Runtime adaptations: roadStraightLong and roadPitStraightLong panels are fitted to the shared original circuit path; environment colors are adjusted; sponsor sign UVs are remapped for project names; the car body and wheels are separated and recolored to match the physics chassis. Driver helmets, race numbers, start lamps, portfolio posters and pit markings are custom additions.

No third-party game code is copied. Circuit layout, AI drivers, physics integration, lap timing and portfolio interactions remain in src/game.
